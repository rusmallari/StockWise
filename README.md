# StockWise

Project Overview

StockWise was developed as a software engineering project focused on building a structured and scalable system for financial analysis and investment education. 
The application emphasizes user-friendly design and clear presentation of financial data to help users learn about stock market fundamentals.

Key Features

User registration and login authentication
Company search functionality for stock research
Investment insights including risk and return analysis
Dashboard displaying company and financial information
Educational focus for beginner investors
